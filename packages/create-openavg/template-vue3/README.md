# OpenAVG Vue3 项目

基于 OpenAVG 核心引擎的 Vue3 视觉小说游戏模板。

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **TypeScript** - JavaScript 的超集
- **OpenAVG Core** - 视觉小说游戏引擎
- **PixiJS** - 2D WebGL 渲染引擎
- **UnoCSS** - 即时按需原子化 CSS 引擎

## 项目结构

```
├── src/
│   ├── assets/          # 静态资源
│   ├── components/      # Vue 组件
│   ├── game/           # 游戏逻辑
│   ├── App.vue         # 根组件
│   └── main.ts         # 应用入口
└── public/             # 公共资源
```
