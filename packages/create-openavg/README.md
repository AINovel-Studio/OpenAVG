# @openavg/create-openavg

快速创建 OpenAVG 项目的脚手架工具。

## 使用

```bash
npx @openavg/create-openavg my-game
cd my-game
pnpm install
pnpm dev
```

## 功能特性

- 🎮 基于 Vue3 + Vite + Pixi.js 的游戏项目模板
- 🎨 开箱即用的游戏菜单系统
- ⚡️ 快速项目初始化

## 生成的项目结构

```
my-game/
├── src/
│   ├── components/     # Vue 组件
│   ├── composables/    # 组合式函数
│   ├── api/           # API 接口
│   ├── App.vue
│   └── main.ts
├── public/
├── index.html
├── package.json
├── vite.config.ts
└── uno.config.ts
```
